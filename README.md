# 🍽️ Zia Restaurant Ordering App

A simple **restaurant ordering system** built with **Python (Tkinter GUI)**.  
Users can order food, see their bill, and enjoy a smooth ordering experience.  

---

##  Features
- Simple and easy-to-use GUI  
-  Fuzzy matching for menu items (e.g., "piza" → "Pizza")  
- Bill calculation with total  
- Light yellow theme with food menu
